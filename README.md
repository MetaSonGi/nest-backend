# Nest Backend

NestJS 기반 백엔드 학습용 스타터입니다. 공식 기본 템플릿에서 시작했습니다.

## 실행

```bash
yarn install
yarn start:dev
```

## 테스트

```bash
yarn test
```

## 기술 스택

- NestJS · TypeScript
